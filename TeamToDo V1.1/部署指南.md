# 维修三处管理平台（TeamToDo）部署指南

## 一、运行模式（重要）

本平台**不搭建任何服务器**，也**不需要专门的服务器机器**：

- 每个人的电脑上各自运行一个本机程序（只监听 `127.0.0.1`，仅自己的浏览器可以访问，对外不开放任何端口）
- 所有数据统一存放在公司公共共享文件夹的数据库文件中，通过共享文件夹实现协同
- 不开启 DHCP、不做端口映射、不修改防火墙——程序默认的行为就是"纯本机"

```
┌────────── 你的电脑 ──────────┐      ┌──── 公司公共共享文件夹 ────┐
│  浏览器 ←→ 本机程序(127.0.0.1)│ ───▶ │  \\10.23.181.219\维修三处\ │
│  （其他人访问不到你的程序）    │ 读写 │  99维修三处管理平台数据库    │
└─────────────────────────────┘      │  └─ tasks.db（唯一数据）   │
       同事电脑（同样结构）──────┘      └──────────────────────────┘
```

## 二、系统兼容性

| 系统 | 支持情况 | 说明 |
|------|---------|------|
| Windows 7 32/64 位 | 支持 | 用 Python 3.8 打包（Python 3.9+ 官方不再支持 Win7） |
| Windows 8.1 / 10 / 11 | 支持 | 32 位程序，64 位系统同样可运行 |
| UOS 统信 / 银河麒麟 | 支持 | 走 Python 源码模式，见第六节 |
| Ubuntu / Debian / CentOS | 支持 | 同 UOS |

**关键点**：`TeamToDo.exe` 是 32 位程序，自带 Python 运行时，
**目标机器不需要安装 Python**，也不需要管理员权限。

## 三、首次部署（管理员操作一次）

1. 在有网络的开发机上生成发布包：

   ```bash
   python build/build.py            # 产出 32 位程序，产物在 dist/TeamToDo/
   ```

2. 检查发布包里的 `config.json`，确认共享文件夹指向正确：

   ```json
   {
     "app": {
       "title": "维修三处管理平台",
       "subtitle": "维修三处任务协同管理平台"
     },
     "server": {
       "host": "127.0.0.1",
       "port": 8765,
       "open_browser": true,
       "lan_access": false
     },
     "database": {
       "folder": "//10.23.181.219/维修三处/99维修三处管理平台数据库",
       "file": "tasks.db"
     }
   }
   ```

   > 路径里用**正斜杠 `/`**（程序会自动转换）；迁移共享位置时只改 `database.folder` 这一项。

3. 把整个 `dist/TeamToDo` 文件夹复制到共享文件夹或 U 盘，分发给每位同事。

## 四、每台电脑的使用步骤（一次性）

1. 把 `TeamToDo` 文件夹复制到本机任意位置（如 `D:\维修三处平台\`）。
2. 双击 **检查共享文件夹.bat** —— 确认本机能访问共享数据库目录。
3. 双击 **启动服务.bat** —— 浏览器自动打开 `http://127.0.0.1:8765`，
   用 `admin / admin123` 登录后**立即修改密码**。
4. 想开机自动运行就双击 **设置开机自启.bat**（后台静默启动，不弹窗）。

常用脚本一览：

| 脚本 | 作用 |
|------|------|
| `启动服务.bat` | 启动并自动打开浏览器（窗口别关，关了服务就停） |
| `停止服务.bat` | 停止本机服务 |
| `打开任务页面.bat` | 服务已在后台时快速打开页面 |
| `检查共享文件夹.bat` | 检测共享数据库目录是否可访问 |
| `共享数据库设置.bat` | 修改共享文件夹地址（迁移时用） |
| `设置/取消开机自启.bat` | 开机自动后台运行 / 取消 |
| `tools\获取便携Python.bat` | EXE 被杀毒软件误报时的备用运行环境 |

## 五、共享数据库注意事项

- 程序自动识别 UNC / 映射网络驱动器路径，并自动改用兼容的日志模式
  （共享盘上禁用 WAL，避免 `disk I/O error`）。
- 多人同时保存依靠 SQLite 文件锁 + 20 秒等待，中小团队（几十人）足够；
  同时编辑高峰偶有"稍等片刻"提示属正常现象。
- **共享盘连不上时程序会拒绝启动**并给出中文提示（防止数据分叉），
  联网后重新启动即可。
- 建议在 `config.json` 里配置自动备份：

  ```json
  "database": {
    "backup_dir": "//10.23.181.219/维修三处/99维修三处管理平台数据库/backup",
    "keep_backups": 10
  }
  ```

  每次启动自动备份一份数据库到该目录，保留最近 10 份。

## 六、UOS 统信 / Linux 部署

1. 确认有 Python 3.6+（UOS 桌面版默认自带）：

   ```bash
   python3 --version
   ```

2. 复制 `backend/`、`db/`、`scripts/linux/` 到本机目录，然后：

   ```bash
   chmod +x scripts/linux/*.sh
   ./scripts/linux/start.sh          # 启动（同样只监听 127.0.0.1）
   ./scripts/linux/stop.sh
   ./scripts/linux/install.sh        # 可选：安装菜单项和快捷方式
   ```

3. 共享文件夹在 UOS 上通过文件管理器挂载（smb://...）后，
   在 `config.json` 的 `database.folder` 里填挂载后的本地路径，例如
   `/home/用户/共享/99维修三处管理平台数据库`。

## 七、升级与维护

- **升级程序**：替换 `TeamToDo.exe`（以及 `server.py`、`static/`）即可，
  共享盘上的 `tasks.db` 不动。
- **改界面名称**：改 `config.json` 的 `app.title`，重启生效，无需重新打包。
- **迁移共享文件夹**：只改 `config.json` 的 `database.folder`，
  把 `tasks.db` 拷到新位置。
- **看日志**：本机 `logs/server.log`。
- **本机个性化覆盖**：`config.local.json`（与 `config.json` 同目录），
  只影响本机，不会被升级覆盖。

## 八、合规说明

- 程序默认只监听 `127.0.0.1` 本机回环地址，**不对外提供任何网络服务**；
  未开启 `lan_access` 时，局域网内其它电脑无法连接本机程序。
- 不需要、也不会提示修改防火墙规则；不做端口映射。
- 若因特殊需要临时开启局域网访问（`server.lan_access: true`），
  用完请改回 `false`。
