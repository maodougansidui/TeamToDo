# TeamToDo 任务协同平台 使用说明

## 一、第一次使用

1. 把 `TeamToDo` 整个文件夹复制到本机任意目录
   （建议 `D:\TeamToDo\`，不要放在需要管理员权限的 `C:\Program Files`）。
2. （仅共享数据库模式需要此步）双击 **检查共享文件夹.bat**，确认显示「[成功] 共享文件夹可以访问！」。
3. 双击 **启动服务.bat**。
   - 命令行窗口会在几秒后自动消失（后台静默启动），**无需等待或操作任何窗口**。
   - 稍后手动打开浏览器，访问 `http://127.0.0.1:8765`
     （或双击同目录下的 **打开任务页面.bat**）。
4. 登录：`admin / admin123`
5. 登录后请第一时间修改密码。

> 若窗口没有自动消失，说明启动失败。请打开同目录下的 `logs\server.log` 查看原因。

## 二、日常使用

| 操作 | 方法 |
|------|------|
| 启动服务 | 双击 `启动服务.bat`（窗口自动消失，后台运行） |
| 打开页面 | 双击 `打开任务页面.bat`，或浏览器访问 `http://127.0.0.1:8765` |
| 停止服务 | 双击 `停止服务.bat` |
| 开机自动启动 | 双击 `设置开机自启.bat`（取消用 `取消开机自启.bat`） |
| 检查共享文件夹 | 双击 `检查共享文件夹.bat` |

数据说明：所有数据都存在公司共享文件夹的数据库里，
**换一台电脑登录看到的是同样的任务**；自己电脑上不保存任何业务数据。

程序只在本机运行，仅自己的浏览器可以访问（地址 `http://127.0.0.1:8765`），
不会对外提供任何服务，不涉及开放端口。

## 三、功能说明

### 任务分发（v3.3 重要变化）

任务采用**逐层下发**的方式，不能跨层级分发：

```
总部 ──→ 生产部 ──→ 检修班组
       └→ 安全部     └→ 运行班组
```

- **只能分发给直接下级部门**：生产部的管理员只能把任务分给「检修班组」「运行班组」，
  不能直接分给更下一级，也不能分给上级或平级部门。
- **可以同时分发给多个部门**：一个任务勾选多个下级部门即可。
- **可以同时指定多个责任人**：多人共同负责同一任务，共享同一份状态，任一人可更新进展。
- **认领并分发**：任务分发到某部门后先进入「部门待认领」。该部门管理员点击
  **「认领并分发」**，在弹出的选择框里可以：
  - 勾选**下级部门** → 任务继续向下分发一层（科室 → 班组）；
  - 勾选**责任人** → 直接指派（只能选本部门及下级部门的人员）；
  - 两者都不选 → 任务认领给自己。
- **角标只看本部门**：侧边栏「部门待认领」旁的数字，只统计分发到**你所在部门**
  且尚未指派责任人的任务，分配完自动归零。上级部门能看到下级的任务，
  但**不能替下级认领**。
- 超级管理员不受「只能发给下级」的限制，可向任意部门分发。

### 任务管理
- **新建任务**：填写标题后，可设置任务类型（普通 / 周期性）、任务种类（日常任务 / 大修任务）、任务来源、**分发部门（可多选）**、**责任人（可多选）**、截止日期、优先级等
- **任务编号**：系统自动生成，格式为 `T+年月日+序号`，如 `T202609080001`，便于追溯
- **任务进展**：列表页直接显示进度条，子任务完成百分比一目了然，无需打开详情
- **周期性任务**：创建后可配置周期规则（每天/每周/每月），系统将自动计算下次触发时间
- **任务汇总**：顶部 6 张卡片实时显示任务总数、待处理、进行中、已完成、已逾期、7天内截止
- **任务关联**：任务详情页可建立关联关系（触发/分解/阻塞），完成后自动通知相关人员
- **反馈**：任务详情可发表反馈，带自动时间戳，支持 Ctrl+Enter 快捷发送
- **筛选**：按状态、优先级、类型、部门、负责人、关键词搜索。
  部门下拉只列出**你所在部门 + 直属下级部门**，不会再出现与自己无关的部门

### 任务可见范围（v3.4）

| 岗位 / 角色 | 能看到的任务 |
|----------|-------------|
| 超级管理员 | 全部部门的全部任务 |
| 处室负责人 / 处室计划工程师 | 本处室**及所有下级部门**的全部任务 |
| 科室负责人 / 科室计划工程师 | 本科室**及所有下级部门**的全部任务 |
| 班组长 | 本班组的全部任务 |
| 班组成员 | 只看到自己的任务 |
| 部门管理员（系统角色 admin） | 本部门及所有下级部门的全部任务 |
| 未分配岗位的普通用户 | 只看到自己的任务 |

### 待确认反馈（v3.4）

责任人（如班组成员）提交反馈后，会同步提醒**分发部门及其上级部门的管理者**
—— 包括班组长、科室负责人、处室负责人和系统管理员，在「待确认反馈」页面
看到该条反馈，确认后即从列表消失。上级部门也能看到，是为了方便领导监督
下级反馈是否及时、内容是否到位。与任务无关的部门看不到该反馈。

### 人员管理
- 添加人员时可为每个人分配**岗位**（权限组），岗位决定该人员可执行的操作
- **删除人员**：每行右侧删除按钮，二次确认后执行。为安全起见，
  不能删除当前登录账号、不能删除超级管理员，也不能删光所有管理员（至少留一名）
- 系统内置超级管理员、管理员、普通用户三种角色；可自定义岗位名称和权限组合

### 岗位权限（v3.4）

- 仅管理员可见，可新建、编辑、删除自定义岗位
- 权限按 **任务权限 / 人员管理 / 组织管理 / 岗位管理 / 其它** 分组展示，
  保存后卡片上会直接列出该岗位已配置的权限项，再次打开会自动回填勾选
- 系统已内置六个岗位预设（如不存在会自动创建，**不会覆盖已有自定义权限**）：

| 岗位 | 可见范围 | 创建任务 | 向直接下级分发 | 认领上级下发的任务 | 反馈 |
|------|---------|:-------:|:-------------:|:-----------------:|:----:|
| 处室负责人 / 处室计划工程师 | 本处室及全部下级 | ? | ? 至科室 | ? | ? |
| 科室负责人 / 科室计划工程师 | 本科室及全部下级 | ? | ? 至班组 | ? | ? |
| 班组长 | 本班组 | — | ? 至班组成员 | ? | ? |
| 班组成员 | 仅自己的任务 | — | — | — | ? |

- **已分配岗位的人员，任务权限以岗位为准**；未分配岗位或只绑定了
  「普通用户」等系统内置角色的人员，保持默认权限不受影响
- 编辑岗位权限后，使用该岗位的所有人员**立即生效，无需重新登录**

### 组织架构
- 支持树形分级显示，可折叠/展开子部门
- 部门负责人可将任务二次分发至部门内个人

### 权限说明

| 角色 | 能做什么 |
|------|----------|
| 超级管理员 superadmin | 全部功能，含岗位权限管理；可见全部任务，可向任意部门分发 |
| 管理员 admin | 管理本部门及下级部门的任务、人员、组织；只能向直接下级部门分发 |
| 普通用户 user | 未分配岗位时：查看和操作与自己相关的任务，可创建/编辑任务 |

> 人员实际权限 = 系统角色权限 + 岗位权限。分配了**自定义岗位**后，
> 任务类权限完全由岗位决定，可精确到「只能反馈」「只能看本班组」这类规则。

## 四、常见问题

**Q：提示「无法访问数据库目录」？**
电脑没有连上公司内网，或没有共享文件夹权限。
1. 打开「计算机」确认能看到共享文件夹；
2. 运行 `检查共享文件夹.bat` 看具体提示；
3. 仍不行请联系管理员开通 `\\10.23.181.219\维修三处\99维修三处管理平台数据库` 的读写权限。

**Q：提示端口被占用 / 打不开页面？**
程序会自动顺延到下一个可用端口。实际端口请看服务窗口，或打开同目录的 `port.txt`。
如果仍然不行，用记事本在程序目录新建 `config.json`，写入：

```json
{ "server": { "port": 9000 } }
```

**Q：双击 exe 没反应 / 被杀毒软件删了？**
用 360、火绒等安全软件把 `TeamToDo.exe` 加入白名单。若仍无法运行，
执行 `tools\获取便携Python.bat` 下载免安装的 Python 环境，之后用 `启动服务.bat` 启动。

**Q：保存时提示等待/超时？**
共享盘模式下多人同时保存会排队（最多等 20 秒），稍等片刻重试即可。
如果频繁超时，联系管理员确认共享文件夹性能。

**Q：忘记 admin 密码怎么办？**
联系管理员处理（共享数据库模式下请勿自行删除数据库文件，那会清空所有人的数据）。

## 五、目录里都是些什么

```
TeamToDo/
├── TeamToDo.exe          主程序（无需安装 Python）
├── server.py             源码（有 Python 的机器可直接运行）
├── static/               网页界面（改动后重启服务即可生效）
├── db/schema.sql         数据库表结构
├── config.json           配置（共享文件夹地址、界面名称、端口）
├── logs/                 运行日志，排错时看这里
├── port.txt              当前实际使用的端口
├── 启动服务.bat          启动
├── 停止服务.bat          停止
├── 打开任务页面.bat      打开网页
├── 检查共享文件夹.bat     检测共享数据库目录是否可访问
├── 共享数据库设置.bat    修改共享文件夹地址（迁移时用）
├── 设置/取消开机自启.bat  开机自动运行
├── 使用说明.txt          本文件
└── linux/                UOS 统信 / Linux 启动脚本
```
